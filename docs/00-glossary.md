# 용어집

- **Case**: 현재 페이지와 사용자가 선택한 문서 묶음 하나의 처리 단위.
- **Document Role**: `primary_notice`, `requirements_checklist` 등 Classify 결과.
- **Parse Element**: 페이지·category·text·coordinates를 가진 원문 구조 단위.
- **Source Record**: Parse Element에 UP²STAGE Source ID를 부여한 canonical record.
- **Evidence**: 실제 Source Record를 참조하는 근거.
- **Search Chunk**: 검색용으로 만든 Section 단위 표현. 그 자체는 근거가 아님.
- **Initial Guidance**: Instruct가 만든 첫 화면용 안내.
- **Quick Question**: 개인 조건 판단을 위해 Extract가 미리 만든 입력 질문.
- **Deterministic Decision**: 숫자·boolean·날짜 등 코드로 재현 가능한 판정.
- **Semantic View**: Parse 구조를 native semantic HTML로 재구성한 접근성 보기.
- **Legacy Unfold**: 과거 프로젝트명. 새 구현에서는 UP²STAGE로 치환.

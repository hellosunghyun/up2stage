# 기능별 권장 커밋 순서

각 항목은 별도 커밋이다. 기능이 화면에서 확인되기 전 다음 항목으로 넘어가지 않는다.

1. `chore: 개발 의존성과 잠금 파일을 고정`
2. `feat: URL 규칙 기반 문서 안내 오버레이를 표시`
3. `feat: 현재 페이지의 첨부문서를 발견`
4. `feat: 분석할 문서를 선택하고 전송 동의를 받기`
5. `feat: Upstage 파일 업로드와 Agent Job 생성을 연결`
6. `feat: Agent Job 진행 상태를 사이드 패널에 표시`
7. `feat: Agent 전체 결과를 표준 Case 데이터로 정규화`
8. `feat: 초기 안내 카드와 원문 근거를 표시`
9. `feat: 추출된 Quick Question으로 조건 입력 폼을 구성`
10. `feat: Quick Question 중복을 제거하고 질문 이유를 표시`
11. `feat: 사용자 입력을 확인하고 분석 동의를 받기`
12. `feat: 조건별 충족 여부와 확인 필요 항목을 표시`
13. `feat: 필수·조건부 제출물 체크리스트를 제공`
14. `feat: Source Registry와 근거 번호를 연결`
15. `feat: PDF 원문 뷰어와 근거 하이라이트를 구현`
16. `feat: 문서 목차와 원문 위치 이동을 연결`
17. `feat: HWP와 HWPX 읽기 전용 렌더러를 연결`
18. `feat: XLSX 읽기 전용 표 뷰어를 연결`
19. `feat: 구조화된 접근성 문서 보기를 제공`
20. `feat: 문서를 섹션 단위로 분할해 검색 인덱스를 생성`
21. `feat: Upstage Search로 관련 문서 범위를 찾기`
22. `feat: Solar 답변과 검증된 Source ID를 연결`
23. `feat: 동일 문서 캐시와 작업 재개 흐름을 제공`
24. `test: 전체 데모 사용자 흐름을 자동 검증`

각 commit 본문에 구현 범위·데이터 흐름·테스트를 작성한다.

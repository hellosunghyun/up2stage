# Demo Smoke Test

발표 전 반드시 실제 Chrome profile에서 반복한다.

1. 데모 URL 진입
2. Overlay 표시 시간 확인
3. Side Panel open
4. 발견 문서 개수 확인
5. 선택·동의
6. Cache HIT 또는 안정적인 Processing fixture
7. Initial Guidance
8. Quick Form options/required/rule 확인
9. Decision breakdown
10. Source badge click
11. Viewer document/page/highlight 이동
12. Accessible View
13. Keyboard-only
14. VoiceOver 핵심 문장
15. Side Panel 닫기/재열기 후 상태 복구

실패 시 Demo를 막는 항목은 P0 cut line보다 우선한다.

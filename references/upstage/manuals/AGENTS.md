# AGENTS.md — references/upstage/manuals

## 적용 범위

`references/upstage/manuals` 아래에 적용하며 루트 `AGENTS.md`를 함께 따른다.

## 책임

사용자가 제공한 Upstage 문서 snapshot을 보존한다.

## 필수 참고

- `references/upstage/manuals/README.md`

## 규칙

- 문서 내용을 편집·요약본으로 대체하지 않는다.
- API 구현 시 해당 원문 line과 실제 Job을 함께 본다.

## 완료 기준

- 문서의 현재 결정과 원본 reference가 구분되어 있다.
- 변경이 다른 폴더의 계약에 영향을 주면 관련 문서와 ADR을 함께 수정한다.
- 기능 구현과 문서 변경을 한 커밋에 무분별하게 섞지 않는다.
